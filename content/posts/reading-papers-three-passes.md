## 第一遍：只看骨架（约 15 分钟）

按顺序只读五处：标题、摘要、引言最后一段、各节标题、结论。目标是回答三个问题，而不是读懂细节：

- 这篇文章想解决哪一类问题？
- 它说自己贡献了什么（新方法 / 新数据 / 新结论）？
- 它属于哪条已有工作的脉络？

读到这里如果答不上来，先别往下读，去补一篇它引用的综述，比硬啃正文划算。

## 第二遍：拆目标函数与实验设计

这一遍要能抄下核心数学表达，并说清每个符号是什么。以监督学习里最常见的经验风险最小化为例：

$$
\hat{\theta} = \arg\min_{\theta}\ \frac{1}{n}\sum_{i=1}^{n} \ell\big(f_{\theta}(x_i), y_i\big) + \lambda \|\theta\|_2^2
$$

拆开看只有四件事：$f_\theta$ 是模型族，$\ell$ 是损失函数，$\frac{1}{n}\sum$ 说明优化的是数据集上的平均，$\lambda\|\theta\|_2^2$ 是对复杂度的惩罚。读论文时把作者改动的那一处圈出来——多数工作的新意只落在其中一项上，比如换掉 $\ell$，或者给 $\lambda$ 加一个调度策略。

行内公式也可以直接用，例如学习率按 $\eta_t = \eta_0 / \sqrt{t}$ 衰减时，前若干步的步长变化远大于后期。

接着看实验表格，重点核对两件事：**baseline 是不是够强**，以及**消融实验是否拆掉了论文声称的那个新部件**。这两点决定了结论的可信度。

## 第三遍：合上论文复述

合上 PDF，用五句话写下来：

1. 问题是什么；
2. 之前做法的瓶颈在哪；
3. 本文改了什么；
4. 用什么实验证明改动有效；
5. 我认为哪里仍然存疑。

写不出来就说明还停在"看懂了"的错觉里，回到第二遍补对应段落。这一步比多读三篇新论文更有用。

## 一张可留存的卡片

| 字段 | 要填的内容 |
| --- | --- |
| 一句话贡献 | 用自己的话，不复制摘要 |
| 关键假设 | 结论成立依赖哪些前提 |
| 验证方式 | 数据集 / 指标 / 最强 baseline |
| 可复现的最小部分 | 只复现哪一个实验最划算 |
| 存疑点 | 下次组会或复现时要问什么 |

{{< note title="下次要验证什么" >}}
挑一篇近期论文，只复现它表格里的一行，看能否得到同量级的结果；把偏差来源记成下一篇笔记。
